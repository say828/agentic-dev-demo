왼쪽 화면의 발급·검증·잠금·멱등 동작은 즉흥이 아니라, 기획 단계에서 EARS로 못박은 Acceptance Criteria를 그대로 실행한 결과입니다.

AC-1회원가입 요청 시 (email, purpose)에 6자리 OTP 발급 + TTL 300초
AC-2OTP가 유효하고 올바르면 계정 생성
AC-3OTP 5회 연속 오답 시 잠금(무차별 대입 방지)
AC-4TTL 300초 경과 시 만료로 거부
AC-5같은 사용자 재요청은 멱등 보장(중복 계정 방지)
AC-6signup_otp 화면이 승인된 디자인 스냅샷과 일치(지금 이 화면)
