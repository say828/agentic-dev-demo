# 싸이월드 미니홈피: 요구사항 원문 (강의 데모용 가상)

> 실재 계정·결제 없음. 도토리·일촌·방문자는 모두 가상 데이터.
> 화면 캡쳐(미니홈피 메인)에서 출발해 백엔드만 로컬로 클론한다.

- 도토리(가상화폐)를 충전하면 잔액이 늘고, 아이템 구매 시 가격만큼 차감된다.
- 잔액이 부족하면 구매를 거부한다.
- 같은 주문은 재요청해도 한 번만 결제된다(이중 결제 방지).
- 일촌은 신청 → 상대 수락으로 양방향 성립한다. 수락 전에는 일촌이 아니다.
- 같은 일촌 신청을 반복해도 한 번만 접수된다.
- 미니홈피 방문은 같은 방문자·같은 날 한 번만 TODAY로 집계된다(누적 TOTAL은 별도).
- 미니홈피 메인 화면(minihompy)은 디자인 스냅샷과 일치해야 한다.
- 기존 방명록 흐름은 도토리·일촌 추가로 깨지지 않는다.
